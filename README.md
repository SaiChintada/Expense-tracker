# 💰 ExpenseFlow

A modern Full Stack Expense Tracker built using **React**, **FastAPI**, **PostgreSQL**, and **JWT Authentication**.

ExpenseFlow helps users manage their personal finances by tracking income and expenses, analyzing spending habits, monitoring savings, and visualizing financial data through an elegant dashboard.

venv\Scripts\activate
